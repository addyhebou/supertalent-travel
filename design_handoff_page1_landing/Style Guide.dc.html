Design system

Reference for a VVIP luxury OTA. Restrained, editorial, minimal — one accent color used sparingly against warm neutrals. Built out for Page 1 (header, navigation, hero, Global Chains mega-menu, search overlay); the same tokens carry through the rest of the app.
